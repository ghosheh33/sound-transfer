# نقل بالصوت (Sound Transfer)

تطبيق ويب (PWA) لنقل **النصوص والصور والملفات الصغيرة بين هاتفين عبر الصوت فقط**:
مكبّر صوت هاتف يُصدر نغمات، وميكروفون الهاتف الآخر يلتقطها ويفك ترميزها.
لا إنترنت، ولا بلوتوث، ولا واي فاي أثناء النقل، ويعمل على أندرويد وآيفون من المتصفح مباشرة.

## التشغيل

التطبيق ملفات ثابتة بلا أي اعتماديات ولا خطوة بناء. يكفي رفع مجلد `sound-transfer/` إلى أي استضافة
**HTTPS** (لأن المتصفح لا يسمح بالميكروفون إلا عبر https)، مثل GitHub Pages أو Netlify أو Cloudflare Pages أو خادمك.

- بعد فتحه مرة واحدة يعمل **بدون إنترنت** (Service Worker)، ويمكن «إضافته إلى الشاشة الرئيسية» كتطبيق.
- للتجربة على الحاسوب: `python3 -m http.server` داخل المجلد ثم افتح `http://localhost:8000`.

## الاستخدام

1. الهاتف المستقبِل: «استقبال» ← «ابدأ الاستماع».
2. الهاتف المرسِل: اختر نصاً أو صورة أو ملفاً ← «إرسال بالصوت».
3. قرّب الهاتفين (10–50 سم) وارفع الصوت.

## السرعات (بعد التصحيح والحماية)

| الوضع | السرعة | صورة 5 ك.ب | متى يُستخدم |
|---|---|---|---|
| متين | ~195 بت/ث | ~4 دقائق | ضوضاء، مسافة، غرفة فيها صدى |
| عادي | ~600 بت/ث | ~1.3 دقيقة | الافتراضي |
| سريع | ~860 بت/ث | ~1 دقيقة | هاتفان متلاصقان وهدوء |

الصور تُصغَّر وتُضغط (WebP/JPEG، أبعاد وجودة قابلة للتعديل، خيار أبيض وأسود) قبل الإرسال، والمعاينة تُظهرها كما ستصل.
النصوص والملفات تُضغط بـ deflate تلقائياً عندما يفيد ذلك.

## كيف يعمل

```
[صفّارة مزامنة 100ms] [نغمة الوضع 60ms] [خانات البيانات …]
```

- **المزامنة:** صفّارة متصاعدة (1→6 كيلوهرتز) يكشفها المستقبِل بالارتباط المتطابق (matched filter عبر FFT)، فيعرف بداية الحزمة بدقة عيّنة واحدة.
- **التضمين:** 16-FSK متوازٍ: 6–8 مجموعات ترددية بين 1.5 و10 كيلوهرتز، كل مجموعة تُصدر نغمة واحدة من 16 في كل خانة (4 بتات).
  التباعد بين النغمات = 1/مدة الخانة (نغمات متعامدة)، مع فاصل حماية يمتص الصدى.
- **المعادلة:** يقدّر المستقبِل استجابة كل نغمة (السمّاعة والميكروفون والغرفة) من الحزمة نفسها ويعوّضها.
- **تصحيح الأخطاء:** ريد-سولومون GF(256) بـ 32–40 بايت تكافؤ لكل حزمة، مع استخدام البايتات الضعيفة الثقة كـ«محو» (erasures) لمضاعفة القدرة على التصحيح، ثم CRC-32.
- **البروتوكول:** حزمة معلومات (الاسم، النوع، الحجم، CRC للملف كاملاً) تتكرر كل 8 حزم، والحزم تُعاد في دورات؛ ما يفوت المستقبِل في دورة يلتقطه في التالية، ويمكنه البدء بالاستماع في أي لحظة.
- كل شيء يعمل داخل المتصفح (Web Audio + AudioWorklet)، ويعالج اختلاف معدّل العيّنات بين الأجهزة (44.1/48 كيلوهرتز) وانحراف الساعة.

## الملفات

| الملف | الوظيفة |
|---|---|
| `js/modem.js` | المضمِّن/كاشف التضمين والمستقبِل المتدفق |
| `js/rs.js` | ريد-سولومون (أخطاء + محو) |
| `js/protocol.js` | تقسيم الملفات، حزمة المعلومات، إعادة التجميع |
| `js/audio.js` | الميكروفون والتشغيل المجدول |
| `js/media.js` | تصغير الصور والضغط |
| `js/app.js` | الواجهة |

## الاختبارات

```
npm test
```

- `rs.test.mjs`: 1600 حالة تصحيح أخطاء ومحو.
- `protocol.test.mjs`: نقل ملف كامل مع فقدان ثلث الحزم في الدورة الأولى.
- `sim.test.mjs`: قناة صوتية محاكاة (تحويل 48→44.1 كيلوهرتز، انحراف ساعة، صدى غرفة، استجابة ترددية غير مستوية، ضوضاء) لكل وضع.

## حدود معروفة

- الصوت قناة بطيئة؛ التطبيق مناسب للرسائل والصور الصغيرة والملفات بحجم كيلوبايتات، لا للصور الأصلية الكبيرة.
- الإرسال في اتجاه واحد (بلا تأكيد استلام)؛ لذلك الافتراضي دورتان.
- على آيفون: يجب إطفاء وضع الصامت، وإبقاء الشاشة مفتوحة.
